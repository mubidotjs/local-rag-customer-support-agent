The Peregrine station stores its field notes on removable paper cards. A technician checks the station housing before each recovery exercise. The maintenance log records the local panel state and the color of the test card. These notes describe preparation only and do not define recovery-code lifetime. Keep the station away from loose packing foam during inspection. The serial label uses plain text and does not contain a recovery code. The inspection sheet belongs to the fictional training workshop. The training ledger records the panel state for the next technician. 

The visitor panel uses a separate training profile. The visitor code remains valid for 3 minutes. Visitor settings apply only to supervised demonstrations and cannot unlock an operator account. The operator panel shows a square icon while visitor training is active. A demonstration is complete when the square icon disappears. Keep the visitor card in the marked sleeve after the session. Visitor-profile timing is unrelated to amber or cobalt operator recovery. The training ledger records the panel state for the next technician. The training ledger records the panel state for the next technician. 

The amber panel is reserved for the warehouse exercise. The workshop keeps an amber card beside the operator station. Operators check that the station has completed its local power test before reading the card. An amber card is not interchangeable with a visitor card. The timer begins when the operator displays the amber code and stops if the session is canceled. The card contains no account password. The training ledger records the panel state for the next technician. The training ledger records the panel state for the next technician. The amber recovery code remains valid for 47 minutes.

The cobalt panel belongs to the archive exercise. The archive exercise uses a different timer from the warehouse exercise. Operators finish the archive checklist before displaying a cobalt code. A cobalt card does not change the visitor profile. The blue label on its sleeve is a filing aid only. The timer resets when the archive exercise is canceled. The local station records completion without sending any messages. The training ledger records the panel state for the next technician. The training ledger records the panel state for the next technician. The cobalt recovery code remains valid for 9 minutes.
