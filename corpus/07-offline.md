# Local use

LumaDesk can configure LumaDock Home without an internet connection after installation.
Display layouts and sleep preferences are stored locally on the device.
Diagnostic reports remain on the computer until the user exports them manually.
To export diagnostics, open Settings, choose Diagnostics, and select Save report.
The diagnostic report contains firmware version, port status, and recent error codes.
LumaDesk never sends diagnostic reports automatically.
