# Getting help

LumaDock support is available Monday through Friday from 09:00 to 17:00 Northstar time.
Support requests are created manually through the Help tab in LumaDesk.
Include the serial number, firmware version, and error code in a support request.
The serial number is printed on the underside of the device.
LumaDock does not offer telephone support in this fictional product program.
No assistant is authorized to send a support request on a customer's behalf.
