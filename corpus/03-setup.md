# Connect LumaDock Home

Connect the supplied 65 W power adapter before attaching LumaDock Home to a computer.
Use the supplied USB-C cable to connect the port labeled HOST to the computer.
The status light turns solid white when setup is complete.
Install LumaDesk version 2.3 or later to configure display and sleep preferences.
LumaDock Home requires Windows 11 or macOS 14 or later.
Linux is not supported by LumaDesk.
