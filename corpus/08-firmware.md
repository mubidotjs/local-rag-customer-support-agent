# Updating firmware

Firmware updates are started manually from Settings, Device, Update firmware in LumaDesk.
Keep the power adapter connected throughout a firmware update.
A firmware update typically takes 3 minutes and restarts the dock once.
Do not disconnect the HOST cable until the status light returns to solid white.
The current stable firmware for this fictional corpus is 2.3.1.
Firmware updates preserve saved display layouts.
