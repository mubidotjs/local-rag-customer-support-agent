# External monitors

LumaDock Home supports one external display at up to 3840 by 2160 pixels at 60 Hz.
The computer USB-C port must support DisplayPort Alt Mode to use an external monitor.
Dual external displays are not supported by LumaDock Home.
Use an HDMI 2.0 cable shorter than 2 meters if the screen flickers.
If a monitor is blank, reconnect the HOST cable and select the HDMI input on the monitor.
